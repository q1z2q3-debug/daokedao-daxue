  • 实核日期：2026-11-23。字频为脚本实核，非估算；某词在原文不作复合词出现者，次数记 0，并注原文实际用字。

三　本书义理名相（原文无对应词）

关键字 出现次数 说明
三才 0 本书义理名相：色属地、受想行属人、识属天；《大学》原文无「三才」一词，其义散见于本末、修身、明德诸目。
一阴一阳 0 本书义理名相，出《易·系辞上》「一阴一阳之谓道」；本书以明德为收（阴）、新民为放（阳）、止于至善为度。经文原文无此二词。

四　索引读法

  1. 复合词与单字分列：如「诚意」是经文复合词，「诚其意」是经文实际句式；两者次数分别标出，避免把句式当生词。
  2. 次数只计底本汉字（含章题标题，不含注疏、义理、今用与〔〕按语）；标 † 者次数含章题同名用字，正文实际出现次数少 † 所标章题那一处。
  3. 某字次数为 0，不代表本书不谈此义；如「慎独」，经文实作「慎其独」，义在 Z06，索引已注原文实际用字。
